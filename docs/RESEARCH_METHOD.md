# Research Method

1. Collect primary-source filings, earnings releases and transcripts.
2. Store each extracted passage with a stable source ID and date.
3. Calculate financial KPIs deterministically in Python.
4. Build forecasts with explicit assumptions.
5. Value the company using DCF, peer multiples and bear/base/bull scenarios.
6. Use an LLM only for synthesis and drafting; never for arithmetic that can be deterministic.
7. Require every material factual claim in the generated report to map to source evidence.
8. Run a verification pass before report export.

This project is a portfolio research tool, not a claim of professional sell-side employment.
